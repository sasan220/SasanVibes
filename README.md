# SasanVibes

Mod do Minecrafta: tekst piosenki 3D na niebie, własne niebiosa, wizuale i HUD.
Wersje: **Fabric 1.21.11** i **Forge 1.8.9 / Lunar Client**.

## Pobieranie
Najnowsza wersja jest w zakładce **[Releases](../../releases/latest)**:
- `SasanVibes-X.Y.Z.jar` – Minecraft 1.21.11 (Fabric)
- `SasanVibes-1.8.9-X.Y.Z.jar` – Minecraft 1.8.9 (Forge / Lunar)

Wrzuć plik do folderu `mods`. Kolejne wersje mod pobierze sam
(menu pod **Right Shift → ⬆ Aktualizacja**).
